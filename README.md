# Glint

### Project Overview
A responsive creative agency website built with HTML5 and CSS3, designed to showcase the agency's services, projects, clients, and achievements. The website provides a clean and visually appealing interface with dedicated sections for the agency introduction, recent works, clients, and contact information.


### Live Demo
[View the Website](https://glintnat.vercel.app/)
### Video Preview
[Watch the Website Demo](https://youtu.be/9SoioOYDyvA)


## Key Features

- Creative agency landing page
- About Us section
- Display company statistics and achievements
- Showcase recent projects and works
- Display client information
- Contact section
- Project inquiry form
- Responsive design
- Image-based portfolio presentation
- Clean and professional user interface

## Installation
1. Clone the repository
```bash
git clone https://github.com/Natalie31706-code/glintnat.git
```

2. Navigate to the project folder
```bash
cd glintnat
```

3. Open index.html in your browser.

## Project Purpose
This project was built to practice HTML and CSS fundamentals while creating a responsive and visually appealing creative agency website. It demonstrates how to structure a professional landing page, create responsive layouts, showcase projects and clients, display company information, and build an intuitive contact section.
